2. Quickstart & Hello World

Earth programs use file extensions .sl, .et, .eh, or .eth. The syntax is clean, combining Pythonic readability with explicit semicolons ; and the define keyword for functions and classes.

Earth (.sl / .et) 
print("Welcome to Earth");

name = "Developer";
print("Hello", name);

define greet(user):
    print("Welcome to Earth, " + user + "!");
    return True;

greet(name);
Command Output
$ earth hello.sl

Hello Developer
Welcome to Earth, Developer!

3. Syntax & Fundamentals

Earth introduces key language innovations designed for high reliability, fault tolerance, and multi-paradigm compatibility:

  • Function Definitions: Declared using define fname(args): or def fname(args):.
  • Line Terminations: Semicolons ; terminate statements cleanly across all blocks.
  • Comments: Both single-line C-style // comment and Python-style # comment are fully supported.
  • Control Flow: Standard constructs if, elif, else, while, for, and loop else.
  • AST Fault Tolerance: Isolated runtime exceptions inside standalone blocks are caught gracefully without terminating background server processes.

4. Object-Oriented Programming & The 5 Inheritance Paradigms

Earth features comprehensive object-oriented capabilities supporting all 5 classical inheritance hierarchies:

Earth (.sl) 
// 1. Single Inheritance
class Animal:
    define speak(self): return "Generic Sound";

class Dog(Animal):
    define speak(self): return "Woof!";

// 2. Multiple Inheritance
class Engine:
    define power(self): return "V8 450HP";

class Electronics:
    define os(self): return "EarthOS 1.0";

class SmartVehicle(Engine, Electronics):
    define info(self): return self.power() + " running " + self.os();

// 3. Multilevel Inheritance
class GrandParent: define g(self): return "Gene-A";
class Parent(GrandParent): define p(self): return "Gene-B";
class Child(Parent): define c(self): return "Gene-C";

d = Dog();
print("Dog speaks:", d.speak());

car = SmartVehicle();
print("Car:", car.info());
Output
Dog speaks: Woof!
Car: V8 450HP running EarthOS 1.0

Sorting Algorithms in Earth 
define quickSort(a):
    if len(a) <= 1:
        return a;
    pivot = a[len(a) // 2];
    left = [x for x in a if x < pivot];
    middle = [x for x in a if x == pivot];
    right = [x for x in a if x > pivot];
    return quickSort(left) + middle + quickSort(right);

data = [42, 17, 89, 5, 23, 64, 11];
sorted_data = quickSort(data);
print("Sorted Array:", sorted_data);

7. Web & REST Backend (`backend.et`)

Earth includes a native HTTP API engine with high-throughput routing. Below is the master backend.et server implementation:

Earth Native REST Server (backend.et) 
import bottle;
import json;
import time;

define api_status():
    response = {
        "engine": "Earth Engine",
        "status": "online",
        "timestamp": time.time(),
        "code": 200
    };
    return json.dumps(response);

define api_compute(a=10, b=20):
    return json.dumps({
        "sum": a + b,
        "product": a * b,
        "power": a ** 2
    });

define start_server(host="localhost", port=8082):
    print(f"[*] Starting Earth Server on http://{host}:{port}...");
    bottle.route("/api/status", "GET", callback=api_status);
    bottle.route("/api/compute", "GET", callback=api_compute);
    bottle.run(host=host, port=port, quiet=True);
