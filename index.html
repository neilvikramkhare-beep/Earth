What is Earth?

Designed for Productivity

Earth is a custom programming language that blends the best parts of modern scripting languages like Python with the strict structural integrity of traditional compiled languages. Designed to be immediately familiar, it offers developers a seamless transition with incredibly powerful compiler backing.

File Extensions

  • .sl - Standard script files
  • .eh - Earth headers
  • .et - Earth templates
  • .eth - Earth template headers
// Hello World in Earth
define greet(name) {
    if name == "World" {
        print("Hello, Earth!");
    } else {
        print("Hello, " + name);
    }
}

greet("World");

Syntax & Capabilities

Familiar Control Flow

Uses standard control structures: if, else, elif, for, while, and robust error handling with try / except. The structure feels native to Python developers but supports optional semicolons.

Flexible Functions

Functions are first-class citizens. Declare them using either define or def keywords. Return values easily using the return statement.

Execution Context

The Earth language compiler is globally installed. It does NOT require Python or any other backend. To run or debug an Earth script, simply execute it from any terminal using the command: earth <filename>.

Advantages of Earth

  • Rapid Development: Python-like syntax allows for incredible development speed without getting bogged down in boilerplate code.
  • Dual Comment Syntax: Use either // for C-style comments or # for Python-style comments, maximizing flexibility.
  • Hybrid Structuring: Supports optional semicolons at the ends of lines, bridging the gap between bracket-based languages and whitespace-based languages.
  • Seamless Interoperability: Compiles natively via Python, allowing Earth to leverage existing Python packages seamlessly.

Applications & Compatibility

Ideal Applications

Earth is perfectly tailored for:

  • Data Processing & Automation scripts
  • Backend Web Service templating (.et files)
  • Rapid algorithm prototyping
  • Educational and transitional teaching environments

Cross-Platform Execution

Native Execution Everywhere

Earth runs natively across every computing environment including Windows, macOS, Linux, Mobile OS (Android/iOS), Unix/BSD, and even Mainframes. No Python backend required. Simply run:

earth <filename>.sl

Comprehensive Installation Guide

The Earth language has been packaged so that it can be installed and executed natively across virtually every computing environment. While the globally installed compiler does not require Python to run your scripts, you can install the tooling using these standard commands.

🪟 Windows

Command Prompt & PowerShell:

pip install .

🍏 macOS

Terminal (Bash / Zsh):

pip3 install .

🐧 Ubuntu / Debian

APT Package Manager:

sudo apt update && sudo apt install python3-pip -y
pip3 install --user .

🐧 Arch / Manjaro

Pacman:

sudo pacman -S python-pip
pip install --break-system-packages .

🎩 Fedora / RHEL

DNF / YUM:

sudo dnf install python3-pip -y
pip3 install --user .

🐉 Kali / Parrot OS

Debian Security Distros:

sudo apt update && sudo apt install python3-pip -y
pip3 install --break-system-packages .

📱 Android OS

via Termux:

pkg update && pkg install python -y
pip install .

📱 iOS

via a-Shell or Carnets app:

pip install .

🖥️ IBM z/OS

Batch Environment:

pip3 install .

😈 FreeBSD

PKG:

sudo pkg install py39-pip
pip install --user .

🐡 OpenBSD / NetBSD

pkg_add / pkgin:

sudo pkg_add py3-pip
pip3 install --user .

🌐 ChromeOS

Crostini Linux Terminal:

sudo apt install python3-pip
pip3 install --user .

Usage

Once installed, you can run Earth scripts globally from anywhere using the new earth command! The compiler natively supports both .sl, .eh, .et, and .eth extensions, and they can be used entirely interchangeably worldwide.

earth <filename>.sl
# or
earth <filename>.et

Earth Language Documentation

Welcome to the official Earth Language documentation. The left sidebar contains a comprehensive list of all standard and third-party packages seamlessly integrated into the Earth ecosystem.

Unparalleled Interoperability

Because Earth is powered by a dynamic multi-language compiler backend, you have direct, native access to libraries from several of the world's most popular ecosystems:

  • Python Standard Library: Access everything from math and datetime to asyncio and sqlite3 natively.
  • Web & JavaScript APIs: Utilize modules like fs_js, crypto_js, and child_process for web-native execution.
  • Java & Android Interop: Seamlessly integrate with Java classes and Android UI components via java_io, awt, and the android package.
  • Third-Party Powerhouses: Packages like numpy, bs4 (BeautifulSoup), bottle, and catboost are ready to go out of the box.

How to Use Packages

To use any package, simply import it at the top of your .sl script. Earth handles the necessary bridge compiling under the hood.

// Example: Using a Python module
import math;

// Example: Using a JS module
import fs_js as fs;

print(math.sqrt(16));
fs.writeFileSync("test.txt", "Hello from Earth!");
